# Clipper Town

An all-ages adventure on the exact map of Newburyport, Massachusetts — the Clipper City.

**Play it: https://clippertown.io** — or download `ClipperTown.html`, a single offline file, and double-click it.

Map data © [OpenStreetMap](https://www.openstreetmap.org/copyright) contributors (ODbL). Elevation from USGS 3DEP via AWS Terrain Tiles.
