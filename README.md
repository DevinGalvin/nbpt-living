# NBPT Living

An all-ages adventure on the exact map of Newburyport, Massachusetts.

**Play it: https://devingalvin.github.io/nbpt-living/**

`NBPT-Living.html` is a single-file offline version — download it and double-click.

Map data © [OpenStreetMap](https://www.openstreetmap.org/copyright) contributors (ODbL). Elevation from USGS 3DEP via AWS Terrain Tiles.
