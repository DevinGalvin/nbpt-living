# Hometown

An all-ages adventure on the exact map of a real place. The first edition charts Newburyport, Massachusetts — the Clipper City.

**Play it in your browser, or download `Hometown.html` (a single offline file) and double-click it.**

Map data © [OpenStreetMap](https://www.openstreetmap.org/copyright) contributors (ODbL). Elevation from USGS 3DEP via AWS Terrain Tiles.
